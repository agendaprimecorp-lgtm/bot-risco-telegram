## 🚀 COMO USAR (3 PASSOS SIMPLES!)

### **PASSO 1: Extraia o arquivo ZIP**
- Clique duplo no arquivo ZIP
- Clique em "Extrair Tudo"
- Escolha a pasta: `C:\Users\SEU_USUARIO\Desktop`

- Navegue até a pasta `bot-risco-telegram`
- Você verá um arquivo: `INICIE_AQUI.bat`

## 📊 Como funciona

1. **Telegram** recebe mensagens do usuário
2. **Claude API** analisa a mensagem
3. **Bot responde** com análise de risco
4. **Calendly** oferece agendamento de consulta
5. **Stripe** processa o pagamento ($200 USD)
6. **Wise** converte para BRL na sua conta

## 🐛 Troubleshooting

**Erro: "Git não está instalado"**
- Baixe em: https://git-scm.com/download/win

**Erro: "Não está em um repositório Git"**
- Certifique-se que abriu o `INICIE_AQUI.bat` dentro da pasta bot-risco-telegram

**Erro ao fazer push**
- Verifique se tem conexão com internet
- Verifique se o GitHub está configurado corretamente
